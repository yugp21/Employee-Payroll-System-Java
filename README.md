# Employee Payroll System in Java 🧾

This is a simple Object-Oriented Programming (OOP) project in Java designed for practicing core OOP concepts such as **abstraction**, **inheritance**, **polymorphism**, and **encapsulation**.

## 📌 Features

- Add full-time and part-time employees
- Calculate employee salaries
- Remove employees by ID
- Display employee details

## 🧠 Concepts Used

- **Abstract Classes**
- **Method Overriding**
- **Inheritance**
- **Encapsulation**
- **Polymorphism**
- **ArrayList (Java Collections Framework)**
